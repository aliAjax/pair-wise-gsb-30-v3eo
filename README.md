# 低温保温排程台（油品冬季夜间配送）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

冬季夜间送油场景：司机以往按里程排车，常到站才发现油温跌破站点接收要求。本应用把配送页扩成
“低温保温排程台”，排车前先估算到站油温，缺温不出车。

## 功能闭环

1. **资料登记**
   - 车辆：车牌、司机，一车多**分仓**；每个分仓登记仓容（吨）与**降温速度**（℃/小时）。
   - 配送单：目标站点、油品、吨数、**装车温度**、**里程**、备注。
   - 站点：名称与**最低接收温度**（接收线）。
2. **排车测算**（待排栏）
   - 预计行驶小时 = 里程 ÷ 夜间均速（页面可改）。
   - 预计到站油温 = 装车温度 − 分仓降温速度 × 行驶小时。
   - 到站油温低于接收线：显示**缺几度**，只能“留在待排（记录缺温）”，不能发车。
   - 达标后确认发车：配送单转在途，**分仓 + 发车日期 + 夜间时段锁定**，同仓同日同时段不能再排第二单。
3. **改派**（在途栏）：选择新车辆/分仓/时段重新测算，达标后**先释放原车锁定再锁定新车**，一次操作完成。
4. **卸油回填**（在途栏）：填写实测到站油温，达标即完成并释放锁定；实测跌破接收线时**自动生成异常处置单**（记录缺几度）。
5. **处置单**：待处置 → 处置中（措施、处理人）→ 已闭环，可按状态筛选。
6. 所有数据保存在浏览器 `localStorage`，**重开页面仍可看到待排、在途和处置单**。

## 分层结构

- `src/types.ts`：领域模型（资料与单据）
- `src/domain/thermal.ts`：判断层，油温测算、缺温、分仓时段锁定等纯函数
- `src/data/seed.ts` + `src/store/persistence.ts`：资料种子与 localStorage 读写
- `src/store/dispatch.ts`：Pinia store，集中所有状态变更并自动落盘
- `src/pages/`、`src/components/`：排程台、资料登记、处置单页面与排车/卸油弹窗
